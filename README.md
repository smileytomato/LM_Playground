The playground for local LLM prompt engineering ✍️🔥


## First Steps
```bash
pip install llama-cpp-python
pip install -U "huggingface_hub"
pip install jupyterlab
pip install ipykernel
pip install -U ipywidgets jupyter
pip install pandas
```

## Temperature

Temperature Ranges and Use Cases

Range	Level	Best Used For
0.0 – 0.3	Deterministic / Low	Code generation, data extraction, math, factual Q&A
0.4 – 0.7	Balanced / Medium	General chat, everyday writing, summaries, RAG tasks
0.7 – 1.0	Creative / High	Brainstorming, storytelling, poetry, marketing copy
1.2 – 1.5+	Experimental / Chaotic	Unpredictable or "drunk" outputs (often incoherent)
